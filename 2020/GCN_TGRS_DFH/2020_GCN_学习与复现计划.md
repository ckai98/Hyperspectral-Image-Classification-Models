# GCN (TGRS 2020) 代码学习与复现计划

## 1. 代码结构分析

原始代码主要由 TensorFlow 1.x 和 MATLAB 脚本组成。

### 核心文件
- **`GCN.py`**: 主要的训练脚本 (TensorFlow 1.x)。
  - `load_data()`: 加载数据（依赖 `.mat` 文件）。
  - `GCN_layer()`: 定义图卷积层的操作 $A X W$。
  - `mynetwork()`: 定义两层 GCN 网络结构。
  - `train_mynetwork()`: 训练循环。
- **`DataGener/`**: 数据生成（MATLAB）。
  - `GCN_DataPreparation.m`: 读取 TIFF 图像，归一化，生成样本。
  - `constructW.m`, `creatLap.m`: 构建 KNN 图和拉普拉斯矩阵。

### 现有逻辑流
1. 使用 MATLAB 读取原始 HSI 影像 (`.tif`)。
2. 转为 2D 矩阵，并在光谱维度归一化。
3. 计算 KNN 邻接矩阵 $W$ 和拉普拉斯矩阵 $L$。
4. 保存为 `ALL_X.mat`, `ALL_Y.mat`, `ALL_L.mat`。
5. Python 脚本读取 `.mat` 文件，传入 TF 图进行训练。

## 3. 详细实施计划

### 阶段一：环境与数据准备 (src/datasets/)

**目标**: 实现 Python 版的数据加载与图构建，完全替代 MATLAB 脚本。

- [ ] **数据加载器 (`hsi_graph_dataset.py`)**:
    - 读取 Indian Pines 数据集。
    - 实现波段筛选（参考原代码：剔除水汽吸收波段）。
    - 实现 Min-Max 归一化。
- [ ] **图构建模块**:
    - 使用 `sklearn.neighbors.kneighbors_graph` 实现 KNN 建图。
    - 计算归一化拉普拉斯矩阵：$L = I - D^{-1/2} A D^{-1/2}$ 或论文中使用的特定形式。
    - 支持将稀疏矩阵转为 `torch.sparse.FloatTensor`。

### 阶段二：模型实现 (src/models/)

**目标**: 使用 PyTorch `nn.Module` 重写 GCN。

- [ ] **GCN 层 (`gcn_layer.py`)**:
    - 输入：特征 $X$, 邻接/拉普拉斯矩阵 $A$。
    - 操作：$\sigma(A X W + b)$。
- [ ] **GCN 网络 (`gcn.py`)**:
    - 输入维度 -> 隐藏层 (128) -> 输出层 (16/Cls)。
    - 包含 Dropout 和 BatchNorm (如果原论文有)。
    - **注意**: 原代码使用了 `tf.layers.batch_normalization`，复现时需在层间加入 `nn.BatchNorm1d`。

### 阶段三：训练与验证 (src/trainers/ & experiments/)

**目标**: 标准化训练流程。

- [ ] **训练脚本 (`train.py`)**:

    - 优化器：Adam。

- [ ] **指标计算**:

## 4. 学习重点

在阅读和复现过程中，请关注以下几点：
1. **图的构建**: 如何将 HSI 像素转化为图节点？（全图构建还是 Patch 构建？本论文是全图构建，还是基于像素采样的图？原代码显示是 `sample_mask`，意味着可能是全图/大子图输入，但只计算部分节点的 Loss）。
2. **拉普拉斯矩阵**: 不同的 GCN 变体对 $L$ 的定义略有不同（这是 spectral GCN 的核心）。
3. **过拟合控制**: GCN 在少样本下容易过拟合，观察 Dropout 和权重衰减的作用。
